# Bash ツールが読み取り専用のコマンドでも glob 展開・複合 `find` 条件を拒否する

- フェーズ: Phase 3
- 状態: 未分類
- 初回観測: 2026-08-16
- 実行モデル: claude-sonnet-5

## 何が起きたか

Phase 3 の実装に着手する前、既存ファイルを一括で確認しようとして次の 2 つのコマンドを
実行したところ、いずれも Bash ツール自身に拒否された（`.claude/settings.json` の許可・拒否
リストではなく、ツール側のコマンド形式チェックによる拒否）。

1. `find resources/views -type f -o -maxdepth 1 -type d | sort`（`lang` ディレクトリの
   直下だけを見るための `-o` を使った複合条件）
2. `for f in app/Models/*.php app/Enums/*.php; do echo "=== $f ==="; cat "$f"; echo; done`
   （複数ファイルをまとめて読むための glob 展開 + for ループ）

いずれも読み取り専用のコマンドで、書き込みを一切伴わない。

## 根拠

```
Contains simple_expansion
```

（2 件とも同一のエラー文言）

## 暫定対応

1 件目は `find` を個別の対象ごとに分けて再実行し解決した。2 件目は for ループを
使わず、複数ファイルを個別の `Read` ツール呼び出しに切り替えて解決した。
テンプレート本体への変更は行っていない。
