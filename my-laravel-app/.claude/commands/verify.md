# Verify: セルフチェック

直前に完了したフェーズの完了基準を満たしているか確認する。

## 共通チェック

すべてのフェーズで以下を確認:

1. `php artisan migrate:status` — 全マイグレーションが `Ran`
2. `php artisan test` — 失敗なし（Phase 1 ではテストファイルが少なくても OK）
3. `vendor/bin/pint --test` — 違反 0（自動修正可能なものは `vendor/bin/pint`）
4. Git status — 意図しない変更がないか

## フェーズ別チェック

対象フェーズの手順書（`.claude/commands/scaffold-phaseN-*.md`）の
「このフェーズの完了基準」セクションを Read し、各項目を順に確認する。
完了基準の一次情報は各手順書側に置き、本ファイルでは重複管理しない。

## 報告フォーマット

チェック結果を以下の形式で報告:

```
✅ クリア: <項目> — 根拠: <実行したコマンドと、判定に使った出力の要点>
❌ 未達: <項目> — 原因: <推測>、対処案: <提案>
⚠️  確認要: <項目> — ユーザー判断が必要な理由 / コマンドで確かめられなかった理由
```

- `✅` には**根拠を 1 行**必ず添える。
- **コマンドで確かめず、docs とコードを読み比べただけの項目は `✅` にしない。**
  `⚠️ 確認要` として、照合した箇所と読み比べた結果を書く（目視照合は見落としても
  green に見えるため、実行による確認と同じ扱いにしない）。

未達がある場合、次のフェーズに進まずに対処する。
